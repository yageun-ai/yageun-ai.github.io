Opus 5.5로 한 번에 만들었다

엉망 엑셀이 클릭되는 대시보드로

Claude Opus 5.5에 프롬프트 한 번 보내서 만든 매출 대시보드. 실제로 보낸 프롬프트 원문, 원본 가상 엑셀, 결과 파일 그대로.

실제로 보낸 프롬프트 (그대로)

Claude Code · 모델 claude-opus-5-5 · 프롬프트 1번 · 결과물 손으로 고치지 않음

이 폴더에 있는 엑셀 파일(2026_3분기_매출_최종_진짜최종.xlsx) 좀 살려줘.
날짜 형식도 제각각이고, 지역 이름도 뒤죽박죽이고, 중복 행이랑 중간 합계 줄도 섞여 있고, 매출 빈칸도 있어.

1. 데이터를 깨끗하게 정리해줘 (뭘 어떻게 고쳤는지도 기록)
2. 정리한 데이터로 임원 보고용 인터랙티브 대시보드를 HTML 파일 하나로 만들어줘
   - 맨 위 핵심 숫자 카드(총매출, 판매수량, 전분기 대비 같은 거 말고 데이터에 있는 것만)
   - 월별 매출 추이, 지역별·제품별 비교, 영업사원 순위
   - 월/지역/제품 필터를 누르면 모든 차트가 같이 바뀌게
   - 데이터 정리 내역도 한 섹션으로 보여주기
   - 세로 폰 화면에서도 보기 좋게, 숫자가 올라가는 애니메이션, 깔끔한 다크 테마
3. 데이터는 HTML 안에 넣어서 파일 하나만 열면 되게

dashboard.html로 저장해줘.

따라 하기

  1. Claude Code(또는 claude.ai)를 열고 모델을 Opus 5.5로 골라요.
  2. 파일이 필요한 프롬프트는 파일을 같은 폴더에 두거나 대화창에 첨부해요.
  3. 나온 HTML 파일을 브라우저로 열면 끝이에요. 결과는 매번 조금씩 달라요.

이 프롬프트는 엑셀 파일을 같은 폴더에서 읽어요. 영상에 쓴 가상 엑셀: sample.xlsx 받기 (파일 이름을 프롬프트 속 이름으로 바꾸거나, 프롬프트의 파일 이름을 고쳐 쓰세요)

▶ 실제 결과물 열어보기 (Opus 5.5가 만든 파일 그대로, 수정 없음)

회사 이름·숫자는 전부 가상 데이터예요. 회사 자료는 넣기 전에 사내 보안 규정부터 확인하세요. Opus 5.5를 쓸 수 있는 요금제는 Claude 공식 요금제 페이지에서 확인하세요.
